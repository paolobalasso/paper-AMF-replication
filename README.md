# Replication package - Paper B

**Benchmark-Relative Objectives and the Learning Signal in Differentiable Portfolio Choice**
Paolo Balasso, University of Padua, Padua, Italy - ORCID 0000-0002-1104-9366

This package reproduces Table 1 (the twenty-one numerical checks) and Figures 1 and 2 of the
manuscript. It uses no market data, no trained model and no proprietary code. Every number comes
from synthetic returns generated by the single-factor model and the seeds declared in Appendix B
of the manuscript.

This archive contains replication code, not a preprint or a copy of the manuscript. Version: 1.0.0. It may be archived as Zenodo resource type **Software**.

## What is inside

| File | Purpose |
|---|---|
| `pubblicazione/verifica_teoremi_paperB_v2.py` | The twenty-one checks. Runs twenty-one numerical checks using central finite differences, algebraic identities, rank and kernel diagnostics, and scaling tests, as appropriate. Test criteria and tolerances are specified in the code. |
| `pubblicazione/paperB_figure.py` | Runs the suite, writes Table 1 as Markdown and draws Figures 1 and 2. This is the entry point. |
| `requirements.txt` | Exact versions used for the reported run. |
| `README.md` | Execution and reproducibility instructions. |
| `LICENSE` | MIT licence text for the replication software. |

## How to run it

Extract the archive anywhere. Open a shell **in the extracted folder** (the one containing this
README) and run:

```
pip install -r requirements.txt
python pubblicazione/paperB_figure.py
```

One command, about ten seconds on an ordinary laptop. The output directory is created
automatically; nothing is written outside the extracted folder.

## What you should see

The suite prints one line per check and ends with

```
21 test su 21 superati
```

(The scripts' console messages and comments are in Italian; the manuscript, this README and all
generated artefacts are in English.) The following files appear:

| Produced file | Corresponds to |
|---|---|
| `pubblicazione/paperB_tabella_verifica.md` | Table 1 of the manuscript |
| `pubblicazione/figure_paperB/figureB1_modulator.{png,pdf,eps}` | Figure 1 |
| `pubblicazione/figure_paperB/figureB2_filter.{png,pdf,eps}` | Figure 2 |

The run asserts that all twenty-one checks pass before drawing anything, so a failed check stops
the script rather than producing a figure that disagrees with the table.

## Reproducibility notes

- All randomness is seeded. Two runs in the same environment give bit-identical Markdown and PNG
  output. The PDF and EPS files differ only inside the `CreationDate` field that both formats
  write from the clock; every other byte, and so the rendered content, is identical.
- Four of the twenty-one checks are regression checks: they separate statements that a less
  careful treatment would conflate (ambient versus learning inertness; the supremum over
  benchmark paths versus the value at a fixed benchmark; pointwise degeneracy versus inertness on
  a whole ordering cell). They are reported in Table 1 like the others.
- Font substitution may change the figures cosmetically if Times New Roman is unavailable;
  matplotlib falls back to DejaVu Serif. No number changes.
- Tested on Windows 10 with the versions in `requirements.txt`. The code uses only numpy and
  matplotlib and has no platform-specific calls.
